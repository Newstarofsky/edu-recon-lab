The red-team modules rely on browser permissions. This page shows their current state so you can see the defensive signals.

Permission status

PermissionState

A page can only read precise location or camera if these say granted. "prompt" means the browser will ask; "denied" blocks it outright.

Defensive checklist

      
    
        
  • Read every camera/location/mic prompt — deny by default.
    • 
        
  • Watch for the browser's active-camera/mic indicator.
    • 
        
  • Verify the domain before typing a password; rely on a password manager's domain match.
    • 
        
  • Be suspicious of pages served from ephemeral tunnels (*.trycloudflare.com, *.ngrok-free.app, *.loclx.io).
    • 
        
  • Enforce phishing-resistant 2FA (passkeys/FIDO2).
